# 座位内卡牌可视化：牌面 / 牌背外观替代「暗牌 × N」计数

政变每名玩家恒持有 2 张影响力牌，暗牌与明牌之和始终为 2。旧界面用文字「暗牌 × N」表示他人未翻开的牌数，并在牌桌下方单列「你的暗牌」面板展示自己的暗牌。我们决定改为在每个座位内直接铺排卡牌外观：自己座位渲染牌面（角色色边框与角色图标），他人座位渲染牌背（45° 斜纹面朝下，无角色信息），已失去影响力的明牌以去饱和置灰的牌面渲染，与暗牌同处座位内一行。同时删除独立的「你的暗牌」面板与「暗牌 × N」计数。

隐藏信息仍然只由服务器持有，本决定不改变信息边界：对手的牌背仅凭公开状态里的 `handCount` 数量渲染，客户端依然拿不到他人的暗牌角色，无泄露。自己座位的牌面来自本人专属的 `privateState`（`Card[]`）。

这样桌面信息密度与认知负担更均衡：玩家在本座位一眼看到自己的牌面与已翻开牌，在他人座位上一眼看到其剩余影响力的牌背数量与已翻开角色，无需在牌桌与独立面板之间来回扫视，契合「一轮一眼」的产品原则。
