# Strong Computer Players, tuned by self-play and chosen per seat by the Host

ADR 0013 aimed Computer Players at "believable, not strong". Players who know the game now want an opponent that plays to win, while beginners still need the believable one. The Host therefore sets a Strength for each Computer Player: standard (the ADR 0013 player, unchanged) or strong. A Computer Player joins as standard, and the Host can switch any one of them during the Lobby Phase.

**A strong Computer Player runs the same heuristics with different numbers.** Every hand-tuned number in `computer.ts` (card worth, action weights, challenge base and cap, bluff willingness, the Temperament ranges, and the rest) lives in one `Tuning` table. `STANDARD` keeps the values ADR 0013 settled on; `STRONG` comes from an evolution strategy that plays thousands of self-play games per generation and keeps the parameters with the highest win rate. The field it is scored against is standard Computer Players plus players who exploit simple patterns: one who never challenges, one who claims Duke every turn, one who never bluffs and never challenges. Scoring against the exploiters as well as the standard player keeps the result from merely preying on the standard player's habits.

**A strong Computer Player also keeps a Deck Memory.** It remembers the cards it put back into the Deck when exchanging, and the cards a Showdown proved and shuffled back. A card it put back is surely in the Deck until someone draws from it, and only probably there afterwards; the Room keeps these returned cards per Computer Player, since they are what a Human Player in that seat saw and could remember, so the boundary of ADR 0002 still holds. The memory sharpens Challenges only; bluffing still looks at what everyone can see. The tuner sets how much weight the memory gets. Against standard Computer Players the memory made no measurable difference to the win rate, at any table size, because the strong player rarely challenges without evidence. It is kept because a Human Player in that seat could use the same information.

**Every Player sees a Computer Player's Strength.** The roster and the seats give both the same badge, in pale gold for a strong one, and the interface names the strong level 进阶 / Advanced. At a physical table everyone knows who sat down to play; if only the Host knew, the Host would hold information the other Human Players lack.

**Considered Options**: Search (ISMCTS with determinizations weighted by a belief model) remains the way to make the strong level stronger still; it is several weeks of work, needs a worker thread so one Room's search cannot stall the others, and must spend a fixed budget so its decision time does not leak its Hidden Cards. Tuning was taken first because it ships in days with no new runtime cost, and it leaves the strong level free to move to search later without changing the Lobby or the protocol. One Strength for the whole Room was rejected because mixing standard and strong seats lets the Host set up a table for a mixed group. Showing Strength only to the Host was built first, with the roster sent per recipient, and dropped for the fairness reason above.

**Consequences**: The self-play bands of ADR 0013 (bluff and challenge rates that look human) apply to standard Computer Players only; a strong Computer Player is held instead to a win rate over standard ones. Re-tuning `STRONG` means rerunning the tuner and the win-rate test, not adjusting numbers by feel. A Temperament still varies a strong Computer Player from Game to Game, but within the narrower ranges the tuner chose.
